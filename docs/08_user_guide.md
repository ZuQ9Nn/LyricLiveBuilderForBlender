# 詳細操作ガイド

[かんたん操作ガイド](07_quick_start.md) の流れに沿って、各パネルの機能を詳しく説明します。画面の名前は、Blender を日本語にしたときの表示です。

---

## 0. 画面の構成

3D ビューのサイドバー（`N` キー）の「LyricLive」タブを使います。上のボタンで 3 つのページを切り替えます。

| ページ | パネル |
|---|---|
| 準備 | 歌詞・フォント・曲・同期 |
| 構成 | おまかせ・試し見・セクション・歌詞の行（行の詳細は 3D ビューの左の別の領域） |
| 演出・出力 | 演出・プレビュー・Unity 出力 |
| （どのページでも一番下） | プレビューの生成（生成・削除・観客カメラ） |

- パネルの見出しをクリックすると畳めます。見出しの右の「∷∷」をドラッグすると、並び順を変えられます。
- サイドバーの左端をドラッグすると、幅を広げられます。行の詳細の領域は左右 2 列なので、広げて使うと見やすくなります。
- **設定を変えたら「生成」**：項目の変更は設定にすぐ入りますが、3D ビューのプレビューは「生成」（または「おまかせで作る」）を押すまで変わりません。見比べながら直すときは「試し見」（§2.2）を使います。
- 「おまかせ」のままの項目は、「おまかせ（斜めの壁）」のように、今おまかせが選んでいるものを括弧で出します。

## 1. 準備のページ

### 1.1 歌詞

| ボタン | はたらき |
|---|---|
| 外部エディタで編集 | 今の歌詞をメモ帳など（.txt に関連付けたアプリ）で開きます。保存すると自動で取り込みます（Blender のテキストエディタは日本語を直接入力できないため） |
| クリップボードから貼り付け | コピーした歌詞を取り込みます。今の歌詞があるときは、確認してから置き換えます |
| ファイルから読み込む | .txt・.lrc を選びます。文字コード（UTF-8・UTF-16・Shift_JIS）は自動で判別します |
| 歌詞を開く | Blender のテキストエディタで見ます |
| 歌詞を読み込む | 歌詞を直した後に、読み直します |

歌詞を入れ直しても、同じ行のタップの時刻や設定は引き継ぎます。

**歌詞の書き方（記法）**（「記法」を開くと一覧が出ます）

| 書き方 | 意味 |
|---|---|
| `[サビ]` `[Aメロ]` `[Intro]` など、1 行だけの見出し | セクション（曲の区切り）の始まり。日本語・英語のどちらでもよい |
| `夜明けの色を/覚えてる` | `/` で区切りを指定。おまかせのとき、区切りごとに順に見せる（カット）。長い行は、区切りが無くても自動で分かれます |
| `*透明*` | 強調（大きく、インパクトのある演出が選ばれやすい） |
| 行末の `!` | 強いアクセント（フラッシュ・きらめきの破裂） |
| `歌詞|注釈` | 注釈（読み込むが、今は表示しない） |
| `[01:23.45]歌詞` | LRC の時刻（その時刻で同期済みになる） |
| `# …` | コメント |
| `[ti:曲名]` `[ar:歌手]` | メタ情報。`[ti:曲名]` を書くと、最初の行が 1.1 秒より後に始まる曲では、イントロに曲名が見出しのフォントで出ます。`[ar:歌手]` も書くと、その下に歌手名が小さく出ます |
| `\!` `\/` `\*` `\|` `\#` `\[` `\]` `\\` | 記号をそのまま文字として出す |

### 1.2 フォント

見出し・明朝・本文・等幅の 4 つの役割があります。少なくとも「本文」を指定します。指定の無い役割は、本文のフォントを使います。足りない文字は一覧に出ます。

> 出力には、フォントの字形がメッシュ（または TextMesh Pro のアトラス）として入ります。フォントのライセンスで、アウトライン化・埋め込み・再配布が許されているか確かめてください。

### 1.3 曲

- 「曲を読み込む」で音声ファイルを選びます。テンポ（BPM）と拍を自動で推定します。
- 「BPM」「最初の拍」は手で直せます（横のボタンで推定し直し）。拍は、拍に合わせる演出（ポップ系の雰囲気のサビなど）に使います。

### 1.4 同期（タップで同期）

歌詞の各行が歌い始める時刻を、曲を聴きながらキーを押して決めます。

| 操作 | はたらき |
|---|---|
| 「タップで同期」 | 曲を最初から流します |
| `T` キー | 今の行の歌い始めにタップ（次の行へ進む） |
| `Backspace` | 1 つ戻す（その行のタップを消し、少し前から流し直す） |
| `Esc` | 終える（それまでのタップは残る） |

- **タップの速さ**：「1×（通常）」「0.75×」「0.5×」から選べます。音の高さを変えずにゆっくり流すので、速い曲でも押しやすくなります。記録される時刻は、本来の速さの時刻です。タップの途中で変えても、そこから速さが変わります。
- **カウントダウン**：オンにすると、流し始める前に「3、2、1」と数えます。
- **この行からタップ**：「構成」のページの「歌詞の行」で行を選び、「この行からタップ」を押すと、その行の約 2.5 秒前から流し直して、その行から先だけタップし直せます。前の行の時刻は残ります。
- **タップの遅延（ms）**：キーを押してから記録されるまでの遅れを差し引きます。時計のボタンで測れます（4 回の予備拍の後、16 回のクリック音に合わせて `T` を押す）。一度測ればファイルに残り、無いときはプリファレンスの値を使います。
- **マーカーから取り込む**：タイムラインのマーカーを、行の時刻として取り込みます（ほかの方法で時刻を付けたとき）。
- 「タップ済み N / M 行」で、進み具合が分かります。タップしていない行は、前の行から推定した時刻になります。

## 2. 構成のページ

### 2.1 おまかせ

| 項目 | はたらき |
|---|---|
| おまかせで作る | 文字の配置・動き・パーティクル・背景・ステージの物体を、曲に合わせて組み立て、プレビューを作ります。押すたびに新しい案 |
| 前の案・次の案 | これまでの案を行き来します（最大 30 件） |
| 雰囲気 | グリッチ・しっとり・ポップ・グラフィック・エディトリアル・エモーショナル・ホラー・全部入り。おまかせの好みになります（ホラーは自分で選んだときだけ） |
| スタイル | 配色と書体の組（JIZURA の 27 種）。サムネイルを押すと一覧から選べます |
| ここだけ変える | スタイル・アクセントの色・雰囲気・文字の構成・パーティクル・背景・ステージの物体の、どれか 1 つだけを振り直します |

- 背景は、スタイルの配色の色になり、セクションの境目で同じスタイルの別の色に変わります（JIZURA と同じ）。
- 鍵を掛けた行やセクションは、おまかせを押しても変わりません。

### 2.2 試し見（Before / After）

「試し見（Before / After）」を押すと、3D ビューの左に 2 つの領域が開き、左に変える前（最後に「生成」したとき）、右に今の設定を、観客の位置から同じ向き・同じ時刻で見せます。

| ボタン | はたらき |
|---|---|
| 確定 | 今の設定でメインのプレビューを作り直します |
| 元に戻す | 選んでいる行（セクション）の項目を、変える前に戻します |
| 消音 | 試し見の間、曲を消します |
| 試し見を更新 | おまかせや「演出」のスライダーを変えたときに、After を作り直します |
| 試し見を閉じる | 2 つの領域を閉じます |

### 2.3 セクション

- 「セクション」パネルには、見出しから決めたか推定かの表示と、「セクションの設定」ボタンだけがあります。
- 「セクションの設定」を押すと、新しいウィンドウが開き、すべてのセクションが上から順に並びます。もう開いていれば、開き直して前に出します。閉じるときは、ウィンドウを閉じます。
- 各セクションは、上に「番号・名前・期間（0:04–0:12）」と鍵のボタン、種別、歌詞。その下が 2 列で、右にパーティクル（折りたたみ）・背景・トランジション、左に実際に使われるもの（パーティクル、その下に背景）です。
- ウィンドウの項目はサイドバーに出ます。狭いときは、サイドバーの左端をドラッグして広げます。項目を変えると、試し見はそのセクションに切り替わります。
- **種別**：「種別：サビ（見出しから）」のように表示だけです。違うときは、歌詞に見出し（`[サビ]` など）を書いて直します。
- **歌詞**：そのセクションに入る歌詞の最初の 1 行と、「すべて見る（N 行）」の折りたたみ。
- **パーティクル 1・2**：サムネイルを押して一覧から選びます。
  - 1 つめの既定は「おまかせ」（セクションごとに雰囲気に合うものを選ぶ）。
  - 2 つめの既定は「パーティクル指定なし」。「おまかせ」にすると、1 つめと重ならないものを選びます。
  - 同じものを 2 つ選ぶと「同じパーティクルが 2 つ選択されています」と出ます。
- **背景**：既定は「おまかせ」（スタイルの色）。空（朝・昼・夕・夜・夜明け・星空）、海の中、宇宙、模様、パノラマ画像なども選べます。
- **トランジション**：背景が変わるときの切り替え方（クロスフェード・ワイプ・広がるリングなど）。
- **実際に使われるもの**：そのセクションで実際に出る背景とパーティクル（サムネイル付き）と、その出どころ（おまかせ・指定・何行目から、など）。
- **鍵のボタン**（各セクションの右上）：パーティクル・背景・トランジションを、今の選択で固定します。

### 2.4 歌詞の行と行の詳細

**歌詞の行**

| 項目 | はたらき |
|---|---|
| この行からタップ | 選んだ行からタップし直します（§1.4） |
| 行に鍵をかける | その行の、今のおまかせの選択を固定します |
| 選び直す | その行だけ、おまかせを振り直します |
| 演出をコピー・演出をペースト | 選んだ行の演出を、ほかの行に写します（1 番と 2 番を同じ見せ方にするなど）。ペーストした行は、コピー元を後で変えても変わりません |
| すべての行を 3D 文字に | 鍵の無い行の 3D 文字を、まとめてオン・オフします |
| 一覧 | 各行に、セクション・開始の時刻・歌詞と、パーティクルを足した印・背景を変えた印。右端の歯車（詳細）で、その行の詳細を開きます |
| 選んだ行の時刻 | 開始・終了（とその出どころ）・セクション・タップの時刻。「手動の時刻」で開始を手で入れられます |

**行の詳細**

一覧の行の右端の歯車を押すと、3D ビューの左に行の詳細の領域が開きます。上に行番号・歌詞・開始と終了・セクション、「行の詳細を閉じる」があります。領域の 3D の部分は、その行を観客の目の位置から見る視点です。一覧で別の行を選ぶと、詳細と視点がその行に切り替わります。ファイルを開き直すと領域は普通の 3D ビューとして残るので、もう一度歯車を押します。

詳細は、上に 3D 文字、その下が左右 2 列です。サイドバーが狭いときは、左端をドラッグして広げます。

| 場所 | 項目 | はたらき |
|---|---|---|
| 上 | 3D 文字・厚み・ベベル | 立体の文字にします |
| 右 | レイアウトと動き | レイアウト・登場・保持・退場をサムネイルで選びます（動きはアニメーションで見せる）。上の欄で「組」（基本・追加・キネティック・タイポ・ホラー）や名前で絞り込めます |
| 右 | パーティクルと背景 | この行で足すパーティクル、この行から背景を変える（そのセクションの終わりまで）。サムネイルで選びます |
| 右 | トランジション | この行から背景を変えるときの切り替え方 |
| 右 | ステージの物体・出し方 | 歌詞のキーワードで出る物体（歌詞から選ぶ・物体なし・キーワードの紋章・内蔵の形）と、その出し方（床から生える・空から降る など） |
| 左 | カット | 1 行を 2〜6 回に分けて順に見せます。おまかせでは、歌詞の `/` の区切りごとに分け、さらに正面に入りきらない長い行は、文字の大きさがそろうよう自動で分けます（1 つに約 5 文字）。「1」にすると、長くても 1 行のまま出します（その分、文字が小さくなります） |
| 左 | 消え方 | 次の行で消える／セクションの終わりまで残る（横に並んで残る） |
| 左 | 視線の誘導 | 行が視野の外に出るとき、光の筋で視線を導きます |
| 左 | 実際に使われるもの | その行で実際に出る背景・パーティクルと、その出どころ |

サムネイルのまとまり（レイアウトと動き・パーティクルと背景など）は、見出しで畳めます。畳むと、選んでいるものが 1 行ずつの文字で出ます。

## 3. 演出・出力のページ

### 3.1 演出

| 項目 | はたらき |
|---|---|
| 動きの強さ・パーティクルの量・装飾・密度・背景の切り替え・視線の誘導・物体の多さ | 全体の強さ。おまかせは雰囲気に合わせて決めますが、手で直せます |
| スペクトラムバー | 音に合わせて伸び縮みするバー（なし・サビだけ・曲全体） |
| コマ打ち | なめらか（毎フレーム。VR に向く）／1 秒に 12 コマ／1 秒に 8 コマ |
| フラッシュ | 画面全体が光る演出。**オフにすると、画面全体が光る・暗くなる演出（ホワイトアウト・暗転のトランジション、拍のパルスを含む）を出さず、明るい背景の色も抑えます**（光に敏感な人への配慮） |
| 独自のアクセント | スタイルのアクセントの色を、好きな色にします |
| パノラマ画像 | 360° の正距円筒の画像。背景で「パノラマ画像」を選ぶと使います |
| おまかせで使う部品 | 種類（レイアウト・登場・パーティクル・背景など）ごとに、おまかせに使わせない部品をオフにします |

### 3.2 プレビュー

- **シード**：おまかせの乱数のもと。同じシードなら同じ案になります。
- **目安の検査**：出力したときの三角形の数・パーティクルの数・マテリアルの数を、Quest の目安と比べます。
- ビュー変換が「標準」でないときは、Unity と色が違って見えるので、「標準の色にする」で直します。

### 3.3 Unity 出力

| 項目 | はたらき |
|---|---|
| Unity プロジェクト | 出力先の VRChat ワールドのプロジェクトのフォルダ |
| Unity エディタ | Unity.exe の場所。2022.3.22f1 が標準の場所にあれば自動で見つかります |
| 曲のフォルダ名 | `Assets/LyricLive/Songs/<この名前>/`（空なら曲のファイル名） |
| マテリアル | VRChat 用（既定）／Unity 標準 |
| モバイル最適化 | Quest 向けに、三角形・パーティクル・マテリアルを目安に収めます |
| TextMesh Pro に変換 | 平らな文字を TextMesh Pro にします（3D 文字の行はメッシュのまま） |
| Udon 同期 | 後から入った人にも再生位置を合わせ、開始・停止のボタン（立方体）を付けます。UdonSharp が要ります |
| Unity へ出力 | 出力します |

- Unity でプロジェクトを開いていないときは、裏で Unity を動かして組み立てます。開いているときは、Unity に切り替えたときに組み立てます（`Tools > LyricLive > Rebuild All Songs` でやり直せます）。
- できた Prefab（`Generated/<曲名>.prefab`）をシーンに置きます。置いた位置が観客の立つ位置です。
- **Udon 同期の開始ボタン**：押すと始まり、もう一度押すと止まります。止めたとき・始めるときは、歌詞やパーティクルが初めの状態に戻ります。曲が終わった後に押すと、最初から始まります。
- 同じ曲名でもう一度出力すると、`Generated/` を作り直します。**Unity で加えた変更は消える**ので、手を加えるのは最後の出力の後にしてください（詳しくは [06_customization.md](06_customization.md)）。

## 5. 自分の 3D の物体を使う

歌詞のキーワードで出る「ステージの物体」に、自分のモデルを使えます。

1. 物体を .blend に入れ、アセットとして登録し、出したい語をタグに付けます（例：`cat`、`猫`）。
2. その .blend のフォルダを、Blender のプリファレンスの「ファイルパス」→「アセットライブラリ」に登録します。
3. このアドオンのプリファレンスで「アセットライブラリ」を選び、「ライブラリを更新」を押します。
4. 辞書に無い言い方は、「追加のキーワード」に `cat=mike,tama` のように書きます。

文字の大きさ・パーティクル・背景などの差し替えは、[06_customization.md](06_customization.md) を見てください。

## 6. 権利について

- **フォント**：出力に字形が入ります。ライセンスを確かめてください。
- **曲・歌詞**：ワールドに曲と歌詞が入ります。利用と公開の権利が必要で、VRChat の規約も守ります。
- **自分の物体・画像**：権利は各権利者にあります。
