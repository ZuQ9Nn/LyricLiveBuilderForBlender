# かんたん操作ガイド

歌詞と曲から、VRChat のワールドで見られる「歌詞のライブ」（文字・パーティクル・背景）を作って、Unity に出力するまでの基本の流れです。細かい設定は [詳細操作ガイド](08_user_guide.md) を見てください。

> 動画版：[movies/quick_start.mp4](../movies/quick_start.mp4)（縦長・約 50 秒・音声なし）

---

## 準備するもの

| もの | 内容 |
|---|---|
| Blender | 5.0 以上 |
| 曲 | 音声ファイル（WAV・MP3・OGG など）。ワールドで使う権利があるもの |
| 歌詞 | テキスト（.txt）。コピーして貼り付けてもよい |
| 日本語のフォント | .ttf・.otf・.ttc。アウトライン化・埋め込みが許可されているもの |
| Unity | 2022.3.22f1 の VRChat ワールドのプロジェクト（Timeline のパッケージ入り） |

### アドオンを入れる

1. Blender で「編集」→「プリファレンス」→「機能拡張の取得」を開きます。
2. 右上の「∨」→「ディスクからインストール」で、`lyric_live_builder-0.1.0.zip` を選びます。
3. 3D ビューで `N` キーを押してサイドバーを出し、「LyricLive」タブを開きます。

サイドバーの上の「準備」「構成」「演出・出力」で、ページを切り替えます。「生成」のボタンは、どのページでも一番下にあります。

---

## 1. 歌詞を入れる（「準備」のページ →「歌詞」）

- 「**クリップボードから貼り付け**」：コピーしておいた歌詞を取り込みます。
- 「**ファイルから読み込む**」：.txt・.lrc を選びます。
- 「**外部エディタで編集**」：メモ帳などで書けます。保存すると自動で取り込みます。

`[サビ]` `[Aメロ]` のような見出しを 1 行で書くと、そこからセクション（曲の区切り）になります。

## 2. フォントを入れる（「準備」のページ →「フォント」）

「**本文**」に、日本語のフォントのファイルを指定します（ほかは空でもかまいません）。足りない文字があると、ここに出ます。

## 3. 曲を入れて、タップで同期する（「準備」のページ →「曲」「同期」）

1. 「曲」の「**曲を読み込む**」で、音声ファイルを選びます。テンポ（BPM）は自動で推定します。
2. 「同期」の「**タップで同期**」を押すと、曲が流れます。
3. 歌詞の各行が**歌い始める瞬間に `T` キー**を押します。
   - 間違えたら `Backspace`：1 つ戻って、少し前から流し直します。
   - `Esc` で終わります（途中まででも保存されます）。
4. 「タップ済み 15 / 15 行」のように、全部の行がタップされていれば完了です。

## 4. おまかせで作る（「構成」のページ →「おまかせ」）

「**おまかせで作る**」を押すと、文字の配置・動き・パーティクル・背景を、曲に合わせて自動で組み立て、3D ビューにプレビューを作ります。

- 押すたびに新しい案になります。「前の案」「次の案」で行き来できます。
- 「雰囲気」と「スタイル」（配色）を選んでから押すと、その方向の案になります。
- 一番下の「**観客カメラ**」で、観客の位置から見た景色になります。`Space` で再生します。

## 5. Unity に出力する（「演出・出力」のページ →「Unity 出力」）

1. 「**Unity プロジェクト**」に、VRChat のワールドのプロジェクトのフォルダを指定します。
2. 「Unity エディタ」は、Unity 2022.3.22f1 が標準の場所にあれば自動で見つかります。
3. 「**Unity へ出力**」を押します。
   - Unity でプロジェクトを開いていなければ、裏で Unity が動いて組み立てます（数分）。
   - 開いていれば、Unity に切り替えたときに組み立てます。
4. Unity で `Assets/LyricLive/Songs/<曲名>/Generated/<曲名>.prefab` をシーンに置きます。置いた位置が観客の立つ位置です。
5. 再生すると、曲に合わせて歌詞のライブが流れます。

> Quest でも見せるときは、出力の前に「モバイル最適化」をオンにします。

## 困ったとき

| こと | 見るところ |
|---|---|
| 文字が □ になる・出ない | 「フォント」に足りない文字が出ていないか。別のフォントにする |
| タイミングがずれる | 「同期」の「タップの遅延」を測る（時計のボタン）。ずれた行は、詳細操作ガイドの「この行からタップ」で直す |
| 気に入らない行がある | 詳細操作ガイドの「歌詞の行と詳細」で、その行だけ変える |
| Unity で何も出ない | 「Unity 出力」の下の状態とログを見る。Unity のバージョンと Timeline のパッケージを確かめる |
